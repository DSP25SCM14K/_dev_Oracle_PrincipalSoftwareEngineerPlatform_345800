## Publish with GitHub Pages

1. Push the repository to `DSP25SCM14K/_dev_Oracle_PrincipalSoftwareEngineerPlatform_345800`.
2. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.
3. The site will be available at `https://dsp25scm14k.github.io/_dev_Oracle_PrincipalSoftwareEngineerPlatform_345800/`.

No build step is required. `.nojekyll` is included. The page intentionally omits LinkedIn and a footer.
